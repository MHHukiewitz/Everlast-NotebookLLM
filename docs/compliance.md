# Everlast Notebook — GDPR and AI Act notes

This document is a demo record, not legal advice.

## Role

Everlast Notebook is a source-grounded research assistant. For typical Mittelstand research use it is a limited-risk / transparency-scope system. A customer DPIA is still required when personal data is processed.

## Lawful basis (demo)

- Demo and interview: legitimate interest in showing a product.
- Customer deployment: contract or documented legitimate interest. Record this in the customer processing register.

## Data map

- Notebook sources, chunks, embeddings, chat, notes, research scratch, and audit events live in PostgreSQL.
- Original files live on disk (`FILE_STORE`).
- Embeddings are personal data. They stay on the machine. They are never sent to OpenRouter or an EU gateway.
- Cloud LLM routes send only the question and retrieved chunks.

## Routes

1. **Ollama (default)** — no third-country transfer.
2. **EU gateway** — OpenAI-compatible. Requires `EU_LLM_BASE_URL` and an AVV / DPA. Allow only models that run in the EU. Gateway residency is not inference residency.
3. **OpenRouter** — interview demo. Standard product is not EU-resident. Requires an explicit transfer notice.

## AI Act Article 50

- Art. 50(1): the UI states that the user talks to an AI system.
- Art. 50(2): PDF and JSON export set `X-AI-Generated` and a human line: “This text was generated by AI. Check the sources.”
- Art. 50(5): the disclosure is visible in the header and footer.

## Rights

- Export: `GET /api/notebooks/{id}/export`
- Erase: `DELETE /api/notebooks/{id}` removes files, chunks, embeddings, messages, artifacts, jobs, and Langfuse traces when configured.
- Retention: notebook data until user delete. Research scratch target: 30 days (`RESEARCH_SCRATCH_DAYS`).

## Logging

Langfuse is optional and self-hosted in Compose. Emails are masked before traces are sent. Do not train models on notebook data.

## Suggested DPIA questions

- Which source types can contain personal data?
- Who is the controller?
- Which model route is allowed for which data class?
- How is erasure proven for vectors and traces?
